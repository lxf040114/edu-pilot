# 装饰器（Decorator）

装饰器是一个「接收函数、返回新函数」的函数，用来在不修改原函数代码的前提下，给它加功能（如日志、计时、权限校验）。

## 基本形态
```python
def log_time(func):
    import time
    def wrapper(*args, **kwargs):
        t0 = time.time()
        result = func(*args, **kwargs)
        print(f"{func.__name__} 用了 {time.time()-t0:.3f}s")
        return result
    return wrapper

@log_time
def add(a, b):
    return a + b
```

`@log_time` 等价于 `add = log_time(add)`。

## 本质
装饰器底层就是闭包：`wrapper` 记住了被装饰的 `func`。带参数的装饰器则是「三层嵌套」：外层收参数，中间收函数，内层是 wrapper。

## 常见用途
- 计时 / 日志
- 鉴权（登录才能调）
- 缓存（functools.lru_cache）
- Flask / 框架的路由注册
