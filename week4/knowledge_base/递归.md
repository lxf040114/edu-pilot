# 递归（Recursion）

递归是函数「自己调用自己」的写法。任何递归都必须有两要素：

## 1. 终止条件（base case）
不能再往下递归的情况，否则无限调用直到栈溢出。

## 2. 递推关系
把大问题拆成「规模更小的同类子问题」。

## 示例：斐波那契
```python
def fib(n):
    if n <= 1:          # 终止条件
        return n
    return fib(n-1) + fib(n-2)   # 递推关系
```

## 示例：嵌套列表求和
```python
def deep_sum(lst):
    total = 0
    for x in lst:
        if isinstance(x, list):
            total += deep_sum(x)   # 子问题
        else:
            total += x
    return total
```

## 注意
- 朴素递归常重复计算（如 fib 指数级），可用备忘录（lru_cache）或改成迭代优化。
- 递归深度受 Python 默认递归栈限制（约 1000 层），太深要改迭代或用 sys.setrecursionlimit。
