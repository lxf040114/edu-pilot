# 列表推导式（List Comprehension）

列表推导式用一行代码生成新列表，语法：`[表达式 for 变量 in 可迭代对象 if 条件]`。

## 示例
```python
squares = [x*x for x in range(10)]
evens = [x for x in range(10) if x % 2 == 0]
pairs = [(i, j) for i in range(3) for j in range(3)]
```

## 对比普通写法
```python
# 普通
out = []
for x in range(10):
    if x % 2 == 0:
        out.append(x)
# 推导式
out = [x for x in range(10) if x % 2 == 0]
```

推导式更短、可读性高、通常也更快（在 C 层循环）。

## 变体
- 集合推导式：`{x for x in ...}`
- 字典推导式：`{k: v for k, v in ...}`
- 生成器表达式：`(x for x in ...)` —— 惰性，省内存，不一次性生成列表

## 何时不用
逻辑太复杂（多层嵌套 + 多个 if）时，推导式反而难读，应改回普通 for 循环。
