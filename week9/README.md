## 二、两个指标（互补）

1. **关键词命中率**（keyword_hit）：参考答案关键词在回答里出现多少。
   客观、可复现，但机械（可能答非所问还命中关键词）。
2. **LLM-as-judge**（llm_judge）：用另一个 LLM 给回答打 0-10 分 + 判断是否编造。
   主观但更接近"真懂"，是当前业界常用的自动评测手段。

两者结合：关键词看"覆盖到没"，LLM 评委看"答对没、编没编"。

## 三、A/B 实验：无 RAG vs 有 RAG

- **基线 A**：直接把问题丢给 LLM（不带教材）→ 可能答得泛、甚至编造
- **变体 B**：先向量检索教材，再带上下文回答（W4/W5 的 RAG）→ 基于教材、可追溯

控制变量：同一个 LLM、同一批问题、同一 temperature，**唯一差别是「有没有教材上下文」**。
这样结果差异只能归因于 RAG 本身。
