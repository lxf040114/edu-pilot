## 一、核心概念自测（参考答案）

1. 教学辅导 Agent = 什么 + 什么 + 什么？
   答：**大模型（决策）+ 教学工具（执行）+ RAG 教材知识（知识）**。
   大模型决定「该出题/批改/查教材」，工具真正去执行，RAG 提供可追溯的教材依据。

2. RAG 作为「工具」和作为「独立模块」有什么区别？
   答：作为工具，由 Agent **按需决定何时查**（灵活）；作为独立模块则是**固定流程**（每个请求
   都先检索）。工具化让「查不查、查几次」成为模型的决策，而不是写死的步骤。

3. 为什么把出题/批改做成工具，而不是写死在 Agent 循环里？
   答：可复用、可评测、可替换——换更好的批改 prompt 或换模型，只改工具内部，Agent 循环不动。
   Agent 只关心「何时调、传什么参」，不关心工具内部实现（关注点分离）。

4. W6 关键词检索 → W7 向量 RAG，解决了什么问题？
   答：关键词是**字面匹配**，长查询/口语（"闭包 外部变量 记住"）会漏检；向量 RAG 是**语义匹配**，
   能召回意思相近但字面不同的片段（实测正确召回「闭包.md」完整定义）。

5. Agent 的「决策」和工具的「执行」分别由谁负责？
   答：决策由大模型负责（结合上下文决定调哪个工具、传什么参数，返回 tool_calls）；
   执行由代码负责（工具函数真正干活，返回结果回传）。
