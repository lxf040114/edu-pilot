# 闭包（Closure）

闭包是指一个函数，以及它「被定义时所在词法作用域」的组合。即使那个作用域已经执行结束，这个函数依然能访问并记住当时作用域里的变量。

## 为什么有用
- 数据私有化：把变量藏在闭包里，外部无法直接修改，只能通过返回的函数间接操作。
- 工厂函数：用一个函数生成多个「带不同初始状态」的函数，例如计数器。
- 回调函数：事件处理、装饰器底层都依赖闭包保存上下文。

## 示例
```python
def make_counter():
    count = 0
    def inc():
        nonlocal count
        count += 1
        return count
    return inc

c = make_counter()
print(c(), c())  # 1 2
```

这里的 `inc` 就是闭包，它记住了 `count`。
